# Восстановление по обновлению

Нужны исходная папка R134 и файл OSGARD_R134_TO_R135_SOURCE_DELTA.zip. Распакуйте из обновления apply_r135_delta.py и запустите:

```bash
python3 apply_r135_delta.py --baseline /path/to/R134 --overlay /path/to/OSGARD_R134_TO_R135_SOURCE_DELTA.zip --out /path/to/new/R135
```

Папка назначения должна отсутствовать. Скрипт сверяет всю базу и результаты по SHA-256 из манифеста; при несовпадении останавливается. Не направляйте вывод в production-каталог. Применение не выполнялось: точная база R134 пока не найдена. После восстановления отдельно проверьте зависимости, сборку и сценарии Godot.

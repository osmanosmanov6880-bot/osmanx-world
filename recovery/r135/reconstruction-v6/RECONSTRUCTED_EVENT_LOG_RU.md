# Журнал учебной реконструкции R135/R136

Журнал — новый код, разработанный при реконструкции. Это локальная симуляция без подключения к промышленным системам; журнал нельзя использовать как промышленный аудит.

Записываются переходы диагностики, тестовые отказы, команды питания и охлаждения, аварийная остановка и её сброс, принятые и отклонённые действия сервисного цикла. Данные остаются в памяти и ограничены 300 последними записями. Кнопка SAVE LOG записывает JSON в `user://osgard_reconstructed_simulation_log.json`, заменяя предыдущий журнал; этот файл сохраняется в пользовательской папке Godot. Содержимое не отправляется по сети.

Проверка Godot headless: существующие сценарии управления, аварийной остановки и сервиса, отклонение неверного действия, чтение экспортированного JSON, ограничение до 300 записей. Отдельная проверка графики и GPU не выполнялась.

Это не восстановление отсутствующих R131–R134 и не подтверждение идентичности оригинальному архиву на 503 МБ.

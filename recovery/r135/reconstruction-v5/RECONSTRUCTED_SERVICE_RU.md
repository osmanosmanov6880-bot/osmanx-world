# Реконструированный сервисный сценарий

Это новая учебная симуляция, созданная по доступному описанию R135. Она не является оригинальным контроллером R134/R135 и не подключена к оборудованию.

Кнопки SERVICE PAUSE → OPEN → INSPECT → CLOSE → RESUME задают последовательность: остановить движение, открыть люк, отметить осмотр, закрыть люк и возобновить движение. Осмотр возможен после полного открытия, запуск — после полного закрытия. При аварийной остановке сценарий прерывается, команды блокируются. Состояние отмечается на экране словом SIMULATED; ручной запуск во время открытого люка блокируется.

Проверено: автоматический headless smoke на Godot 4.6.3, включая отклонение неверного порядка действий и проверку блокировок. Физическая GPU и визуальная проверка интерфейса не проводились. Логику нельзя использовать для управления реальным оборудованием.

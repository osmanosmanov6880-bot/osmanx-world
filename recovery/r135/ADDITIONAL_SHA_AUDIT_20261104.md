## Как повторить

Сканер: `recovery/r135/tools/scan_recovery_sources.py`.

```bash
python3 recovery/r135/tools/scan_recovery_sources.py \
  --manifest recovery/r135/OVERLAY_MANIFEST.json \
  --source /path/to/OSGARD_R134_TO_R135_SOURCE_DELTA.zip \
  --source /path/to/OSGARD_R135_PBR_GLB_ASSETS.zip \
  --source /path/to/OSGARD_M186_INTEGRATION_LAB_FINAL_2026-10-28.zip \
  --output /tmp/r135_sha_audit.json
```

Следующие источники для приоритетной проверки: исходный `OSGARD_R134_CINEMATIC_GODOT_FULL_PROJECT.zip`; недоступный пока архив checkpoint 180; скрытые архивы в прежних чат-сессиях; вложения/артефакты отдельных GitHub Actions до 24 октября.

**Запрет:** не объявлять 503-МБ оригинал восстановленным, пока не найдено и не проверено всё исходное дерево либо исходный архив с собственной контрольной суммой.

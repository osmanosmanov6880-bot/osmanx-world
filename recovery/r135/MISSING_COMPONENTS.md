# Отсутствующие компоненты

1. Исходный ZIP OSGARD_R135_CINEMATIC_GODOT_FULL_PROJECT.zip и его подтверждённая контрольная сумма.
2. Точная база R134: 193 файла с хешами из OVERLAY_MANIFEST.json. По истории она находилась в OSGARD_R134_CINEMATIC_GODOT_FULL_PROJECT.zip.
3. Подтверждение работоспособности восстановленного проекта в Godot, сценариев и аппаратной GPU.

Для восстановления следует найти оригинал ZIP или точную базу R134 в прежней среде, резервных копиях, подключённых накопителях или Git-истории; затем сверить каждый файл с манифестом. Совпадение только имени и размера недостаточно.

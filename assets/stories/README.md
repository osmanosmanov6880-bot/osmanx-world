# OSMANX STORIES — публикация исходных видео

Состояние: страница `/assets/stories/index.html` и ссылки готовы, но видео **не считаются опубликованными**, пока их файлы реально не размещены в `assets/stories/media/`.

## Структура файлов

Положите готовые MP4 в `assets/stories/media/` со следующими именами:

01-restaurant.mp4, 02-fashion.mp4, 03-dentistry.mp4, 04-auto.mp4, 05-fitness.mp4, 06-education.mp4, 07-coffee.mp4, 08-return.mp4, 09-appointment.mp4, 10-construction.mp4, 11-logistics.mp4, 12-shoes.mp4.

Не используйте временные прямые ссылки Runway в HTML: их авторизация истекает, и плееры перестанут работать.

## Видео и производительность

- Соотношение 9:16, каждый ролик ≈15 секунд.
- Оптимизированная версия для веба: H.264, 720×1280, без обязательной звуковой дорожки, faststart.
- Для каждого файла можно положить постер `assets/stories/posters/<имя>.webp`.
- Плеер начинает загружать MP4 только после нажатия. Если файла нет, кнопка остаётся недоступной.
- После загрузки проверьте `curl -I https://osmanx.world/assets/stories/media/01-restaurant.mp4`: статус 200, Content-Type video/mp4 и ненулевой размер.
- Проверьте 12 роликов на телефоне и компьютере; только затем публикуйте ссылку на странице.

## Безопасность и достоверность

Это постановочные AI-видеосцены, не настоящие отзывы и не доказательства результатов для конкретных бизнесов. Сайт прямо указывает это рядом с историями.

## Публикация

Сайт развёртывается из `main` через `.github/workflows/deploy.yml`. Рабочая ветка `feature/osmanx-video-stories-20261119` не должна включать чувствительные токены доступа к Runway.

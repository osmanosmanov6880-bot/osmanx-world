Guest Intelligence / R13 / Защищённый кабинет

Результаты, которые можно проверить.

Заявки, проведение пилота, обезличенные наблюдения, проверка вторым сотрудником и отчёт для владельца. Авторизация — через существующий защищённый Industry API.

Не демонстрация успешных продаж. Для входа требуется действующий аккаунт сотрудника и работающий сервер. Если API ещё не развёрнут, кабинет покажет недоступность и не сохранит введённые сведения.

Вход сотрудника

Публичной регистрации нет. Владелец компании добавляет сотрудников через приглашения. Пароль не записывается в хранилище браузера. Принять приглашение.

—

                  R13 / Безопасность измерений

                  Остановка сбора и контроль качества

                  Любой сотрудник с правом записи может остановить сбор именно этого пилота. Возобновляет только другой владелец или управляющий после отдельной проверки. Защита работает на сервере, даже если запросы отправлены не из этого кабинета.

                  Состояние безопасности загружается.

                  Предупреждения по агрегатам не доказывают причины потери гостей.

                    Предупреждения являются основанием для ручной проверки; они не блокируют пилот сами по себе. Экстренная остановка блокирует записи и подачу результатов до решения другого руководителя. Этот модуль не запускает production API и не разрешает обрабатывать личные данные.

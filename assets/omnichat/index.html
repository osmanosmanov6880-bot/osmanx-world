01 / UNIFIED INBOX

Все обращения

Единая панель диалогов, статусы, распределение по сотрудникам и история событий.

02 / PROVIDER INTEGRATIONS

Подключение каналов

Адаптеры и вебхуки официальных API. Наличие интеграционного кода не означает одобренный аккаунт.

03 / OPERATIONS

Контроль доставки

Сверка отправки и повторов, очереди, ограничения по организациям и диагностические сигналы.

04 / SECURITY

Разделение компаний

Роли, сеансы, tenant-bound операции и защита от повторной обработки входящих.

05 / ANALYTICS

Операционная аналитика

Нагрузка на операторов, статусы переписок, время ответа и контроль отклонений.

06 / DEPLOYMENT

Полный серверный проект

Docker Compose, PostgreSQL, Alembic, Linux/Windows запуск и набор автоматических проверок.

ACTIVATION / DEPLOYMENT

Как запустить
настоящий OmniChat.

Для запуска на VPS нужны отдельная серверная служба, PostgreSQL, HTTPS и защищённый путь через Nginx. Действующий статический деплой-пользователь не может выполнить эти настройки.

Черновик

Фактические показатели разрешено вводить только по подтверждённым материалам. Идентификаторы доказательств остаются в закрытой базе.

Проверенные итоги по дням

Публичные точки карты

Только добровольно разрешённые сведения. Публичные координаты округляются примерно до 100 метров.

Опубликованные документальные эпизоды

Перед утверждением Worker проверит доступность видеоматериала и тип файла, если указан реальный выпуск.

Входящие обращения

Обращения видны только модераторам. Изменения статуса и удаления фиксируются в журнале, без публикации личных данных.

Уведомления о выпусках

Отправка разрешена только подтвердившим email зрителям, для уже опубликованных выпусков и после утверждения. По умолчанию выключена серверным флагом.

Media Studio — документальные выпуски

Одноразовая загрузка в Stream по разрешению редактора. До независимой проверки прав и отдельной публикации зрителям видео недоступно. Размер загрузки до 200 MB; большие файлы требуют отдельного resumable tus-процесса.

Календарь 10 выпусков

План не равен публикации. В назначенную дату можно раскрыть только уже утверждённый и готовый материал. Время хранится в UTC.

Архив и восстановление

В R2 хранятся только зашифрованные редакционные черновики. Частные контакты, подписки и ключи в копию не входят. Восстановление меняет только черновик, не публичный сайт.

История публичных версий

Безопасная публикация

Личные контакты, телефоны, внутренние CRM-записи, точная локация встреч и исходные доказательства не входят в публичный API. Подпись Cloudflare Access проверяется криптографически. Для редактирования и утверждения используются отдельные роли; для защиты от CSRF сервер проверяет Origin.

Страница не сохраняет содержимое ответов API в localStorage. Кнопка «Опубликовать» выполняет отдельную серверную операцию, а не меняет локальную надпись.

# OSMANX MOSCOW 1000 — R8

R8 продолжает мобильный штаб R6–R7. Открывайте `/moscow-1000/` по HTTP(S); API, вход и офлайн-оболочка не запускаются двойным щелчком по HTML из архива.

## Пять завершённых блоков

1. **Ориентиры на карте.** Выбор маркера или строки списка открывает карточку с реальными публичными координатами, источником статуса и ссылкой OpenStreetMap. Поиск работает внутри выбранного дня, понимает регистр и ё/е. Ориентир не означает состоявшийся визит. Линия остаётся схемой соединения точек, а не проверенным пешеходным маршрутом.
2. **Навигация и сохранённые места.** URL хранит день, экран, вкладку аналитики/журнала и выбранную точку. «Назад» и «Вперёд» восстанавливают это состояние. «Поделиться» использует системное меню, копирование или поле для ручного копирования. «Сохранить» явно добавляет до 20 закладок в этот браузер. Закладки не синхронизируются между устройствами и не сохраняют названия/заметки контактов. Ссылка не меняет права доступа к сайту.
3. **Полный бюджет.** Приватная админка показывает итоги всей серверной выборки, дни, категории и остаток плана 100 000 ₽. Фильтры не меняют общий итог экспедиции. Расход редактируется с проверкой ревизии; при конфликте введённые поля сохраняются и требуют отдельного подтверждения новой основы. Суммы хранятся в целых копейках.
4. **Выгрузки владельца.** Раздел «Данные» выдаёт JSON всех операционных записей или CSV контактов/расходов. Сервер создаёт согласованный снимок; браузер проверяет SHA-256 перед скачиванием. Это выгрузка для хранения и анализа; автоматический импорт и восстановление не реализованы. Предел — 10 000 строк каждой выбранной таблицы и 8 MiB итогового файла. Превышение возвращает явную ошибку, без обрезки данных.
5. **История действий.** В том же разделе доступны серверные события контактов, расходов, квестов, публикаций и выгрузок с фильтрами, аккаунтом, московским временем и стабильной пагинацией. Содержимое контактов в историю не копируется.

## Обновление

- Применить миграции API по порядку, включая `0007_r8_command_ledger.sql`; после этого развернуть frontend и API одного выпуска.
- Для отдельного Site используется соответствующая дополнительная миграция `0002_r8_command_ledger.sql`. Предыдущие миграции не переписываются. Тестовые контакты и расходы не добавляются.
- Офлайн-кеш публичной оболочки: `osmanx-public-shell-r8.3`. При обновлении публичных файлов увеличивать его имя. После установки нового worker открытой странице может потребоваться обновление.
- Админка, API, OAuth и картографические тайлы не входят в кеш оболочки. Публичные снимки R7 по-прежнему действуют не более суток.

## Вход владельца

Страница `/moscow-1000/admin/` использует серверный Google OIDC из R6. Нужны настоящие `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, секрет сессии и разрешённый Google-адрес. Ключи задаются только в окружении сервера. До полной настройки личный штаб закрыт; обхода или демонстрационного входа нет.

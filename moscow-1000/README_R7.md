# R7 — использование и обновление

Открывайте `/moscow-1000/` по HTTP(S). Двойной щелчок по HTML внутри ZIP не запускает API, авторизацию и service worker. Старая редакционная страница сохранена по `/moscow-1000/serial/`.

## Зрителю

Выбор дня переключает штаб, карту, сводку и квесты. До публикации автором показатели обозначены прочерками. После первого открытия с сетью интерфейс плана и квесты могут открываться без сервера. Сводка хранится не дольше суток и явно помечается как сохранённая. Новые картографические тайлы требуют сети. Полная офлайн-карта не входит в этот выпуск.

## Автору

Вход: `/moscow-1000/admin/`. Google OAuth требует настоящих клиентских настроек и разрешённого адреса администратора. На странице есть проверка готовности и точный callback. Инструкция: `admin/google-setup.html`.

Поиск контактов и фильтры применяются ко всей серверной выборке. «Есть следующий шаг» показывает незакрытые записи с указанным действием. «Без активного шага» включает записи без следующего действия и закрытые отказом/договором.

Сохранение черновика на устройстве выключено по умолчанию. При включении поля контакта записываются в IndexedDB на семь дней для текущего аккаунта; это не зашифрованное хранилище. Выход удаляет копию. При потере ответа на сохранение повторите ту же попытку указанной кнопкой: сервер не создаст дубль. Самостоятельной фоновой отправки нет. Черновик расходов сохраняется только в текущей вкладке.

## Разработчику

1. Применить миграции API по порядку, включая 0006.
2. Развернуть frontend и API из одного выпуска.
3. Проверить `node --test tests/moscow-1000-*.test.mjs` на Node.js 22 или новее с `node:sqlite`.
4. Для любого следующего выпуска публичных файлов увеличить имя CACHE в `command-sw.js`. Текущий кеш: `osmanx-public-shell-r7.1`. Новый worker получает полный набор публичных файлов до активации. Открытая страница может потребовать обновления после установки новой версии worker.
5. Не расширять кеш на `/admin/`, `/editor/`, `/api/` или OAuth. Не размещать ключи в JavaScript/HTML, Git и manifest.

Подробности API и повторов: `services/moscow-1000-api/README_R7_COMMAND.md`. Итоговая проверка и ограничения: `TECH_REPORT_R7.md`.

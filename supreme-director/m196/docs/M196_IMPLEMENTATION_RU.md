# M196 — инженерный журнал и критерии проверки

**Дата:** 2026-11-05. **Рабочая ветка:** `recovery/supreme-director-m187-20261104`, PR #7. **Релиз:** LOCAL_ONLY / PRODUCTION_NO_GO.

## Реализованный объём

Добавлены 4 таблицы SQLite: `delivery_projects`, `delivery_stages`, `delivery_work_links` и `delivery_events`. Миграция является добавочной для M195; не перезаписывает CRM и существующие задачи. Добавлены 9 операций (создание, список, получение, этап, изменение проекта, связь/отвязка задач, чтение истории).

Проверки:

1. Транзакционная идемпотентность общих запросов, одна запись на один ключ операции.
2. Tenant isolation: проекты и этапы выбираются по `tenant_id`; связь с CRM-активностью должна относиться к тому же клиенту и сделке.
3. RBAC: владелец или создатель проекта управляет этапами; только владелец/назначенный сотрудник привязывает задачу; viewer получает редактирование запрещено и не видит персональные детали задач.
4. Optimistic locking: `expected_version` обязателен для изменения этапа, проекта и привязки задачи.
5. Project state machine: planned → active → completed/cancelled; закрытый проект нельзя повторно открыть.
6. Milestone state machine: pending → active → done. Предыдущий этап обязан быть завершён, а все привязанные задачи иметь статус `done`.
7. Двухсторонний локальный аудит: добавленная запись в `work_history` и журнал `delivery_events`, в котором проверяется цепочка SHA-256. **Без независимого внешнего якоря** перезапись привилегированным администратором не исключена.
8. Русский UI: встроенный новый раздел «Проекты» со списком, этапами, прогрессом, привязкой задач и операциями на живом HTTP API.

## Контроль качества

- Модульные тесты M196 проверяют создание, чтение, зависимости, авторизацию, SQL-модель, параллельные изменения, запрет двойного завершения и HTTP. Тестовый набор включает повторный запуск базовых кейсов при HTTP setup для проверки изоляции сетевого режима.
- Регрессионные проверки M192–M195 не изменены и должны оставаться зелёными.
- `node --check` и `verify_source.py` включены в CI. Браузерная визуальная приёмка не подтверждена в текущей ограниченной среде: Chromium вернул `ERR_BLOCKED_BY_ADMINISTRATOR` даже для `127.0.0.1`. Не маскировать её скриншотами.
- Объявлять M196 завершённой можно только для локального функционального объёма. Исходная кампания на 180 пакетов **не выполнена** и не подтверждена.

## Восстановление и откат

Новые таблицы не заменяют M195. Безопасный откат на старый код: остановить M196 и снова запустить M195 на резервной копии исходной БД, не пытаясь выполнять старые миграции поверх боевых данных. **Не удалять** таблицы вручную. Проверить резервную копию/контрольную сумму заранее и задокументировать точный Git SHA отката.

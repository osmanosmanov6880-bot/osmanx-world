# Wave 7 — визуальные модели, формы и безопасные изменения данных

## Реализовано
- `model_editor.py`: добавление модели, нового типизированного поля,
  изменение отображаемых названий. Операции проходят через авторизацию
  проекта и транзакцию SQLite `BEGIN IMMEDIATE`.
- Новые обязательные поля при наличии записей требуют проверенного значения
  по умолчанию. Миграция допускает **не более 500 записей** за один проход.
  Хеши, версии записей и история спецификации обновляются атомарно.
- `local_http.py`: локальные API модели/поля/названия/история миграций,
  по-прежнему только `127.0.0.1` и токен.
- Русская визуальная консоль: создание модели, поля, выбор типа, начальные
  значения, связь с другой моделью, просмотр миграций.
- Новая секция страницы `form`: статическое представление реальных полей.
  Отправка из предпросмотра отключена; защищённый CRUD находится во вкладке
  «Данные».
- `test_wave7_schema.py`: ограничения, права доступа, отказ с полным
  откатом, сохранность существующих записей, реальный TCP/WSGI POST.
- `browser-console.mjs`: end-to-end проверка интерфейса моделей, перенос
  существующей записи и создание секции формы в Chromium.

## Критерии безопасности
Никаких удалённых SQL-миграций, пользовательского исполнения кода,
открытого HTTP-сервера, онлайн-форм без авторизации или деплоя. Добавляемые
связи с другими моделями не получают автоматически существующих записей.
Изменения ограничены локальной тестовой базой. Неизвестные/противоречивые
структуры отклоняются.

## Воспроизведение
Из корня репозитория, Python 3.11+ и Node 22+:
```bash
export PYTHONPATH="$PWD/supreme-director/campaign180"
python -m unittest discover -s supreme-director/campaign180/tests -p 'test_*.py' -v
node --check supreme-director/campaign180/assets/console.js
node supreme-director/campaign180/tests/browser-console.mjs
```
Последняя команда запускает только временный локальный сервер и Chromium.

Это **частичный код** для TITAN-X20/X21/X24/X25, а не независимая
приёмка оригинального KRAKEN/DevSwarm/Command. 0/180 независимо принято.

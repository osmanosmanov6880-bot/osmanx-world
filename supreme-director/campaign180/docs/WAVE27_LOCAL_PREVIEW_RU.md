# OSGARD — локальная интерактивная версия (Wave 27)

Это реальный программный интерфейс с SQLite, а не макет и не статичный
HTML-файл. Доступны задачи, управление командой, планирование ресурсов,
варианты назначений, подтверждение решений, откат, контрольные замеры
и CSV-отчёты. Все данные демонстрационные и создаются локально.

## Как запустить на компьютере

1. Скачайте ZIP из успешного GitHub Actions workflow. Извлеките папку
   OSGARD_LOCAL_PREVIEW полностью.
2. Установите Python 3.11 или новее, если его нет. Сторонние пакеты не нужны.
3. Windows: откройте start.cmd. macOS/Linux: выполните "sh start.sh"
   в терминале внутри папки. Также работает "python3 run_local.py".
4. На том же компьютере откройте http://127.0.0.1:8765/console.
5. Скопируйте токен, показанный в окне запуска, в поле входа интерфейса.
6. Откройте раздел «Задачи» и попробуйте функции Wave 18–26.

## Android

При наличии Python 3.11+ в Termux можно распаковать папку и выполнить
"python run_local.py", затем открыть http://127.0.0.1:8765/console
в браузере этого же телефона. Один ZIP без Python не является APK
и не запускает сервер сам по себе.

## Как сохранить результаты

Все изменения записываются только в local-data/preview.sqlite3 в папке
распакованного демонстрационного приложения. При новом запуске
демоданные сохраняются. Если нужна чистая база, остановите процесс
и вручную переместите local-data в безопасное место.

## Проверяемые ограничения

- Python сервер слушает только адрес 127.0.0.1, а не публичную сеть.
- Токен сгенерирован случайно при каждом запуске и не включён в ZIP.
- Токен нельзя публиковать или отправлять третьим лицам.
- Архив включает CHECKSUMS.json с SHA-256 каждого исходного файла,
  исходный Git-коммит и дату без пользовательских данных.
- Пакет создаётся и запускается в изолированном CI только после проверки.
- Приложение **не задеплоено в production**.
- Независимая приёмка исходных 180 задач **0/180**, она не подменяется
  успешными тестами и демонстрационным запуском.
- Публичные интеграции, платежи, реальные клиенты и удалённый доступ
  сюда не входят.

## Скриншоты

Отдельный GitHub Actions артефакт «osgard-original180-browser-screenshots»
содержит реальные снимки работающего Chromium на компьютере и телефоне.
Откройте в нём index.html после скачивания/распаковки: это галерея
результатов QA, а не имитация API.

## Как проверить архив

Список точных SHA-256 хранится в CHECKSUMS.json. Для проверки из полного
репозитория используйте:

python -m campaign180.local_preview_bundle verify --archive PATH_TO_ZIP

Для запуска изолированного теста настоящего SQLite/API из ZIP:

python -m campaign180.local_preview_bundle smoke --archive PATH_TO_ZIP

Запуск smoke не открывает публичный TCP-порт.

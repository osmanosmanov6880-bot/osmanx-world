Разрешено только для поля без существующих связей, включая удалённые записи. Действующие связи не перенаправляются автоматически.

СВЯЗИ / ПЕРЕНОС С ДАННЫМИ

Перенос действующих связей

Для каждого старого ID явно выбирается новая запись. Угадывание по имени, автоматическое объединение и перенос чужих записей исключены.

Каждый новый ID можно выбрать один раз. Для таблиц более 100 вариантов нужен отдельный проверяемый скрипт миграции.

РЕВИЗИИ / БЕЗ ПОТЕРИ ДАННЫХ

История и восстановление

Проверь различия, затем создай новую версию на основе старой. Клиентские записи остаются нетронутыми; несовместимые схемы моделей блокируются.

Ручное подтверждение

Выбрать версию

Проверяется исходная SHA-256-сумма, принадлежность проекту и идентичность схем данных. Восстановление не выполняется на этом шаге.

Результат проверки

Выбери версию и нажми «Проверить».

Восстановление создаст новую ревизию. Все существующие записи, история и связи останутся без изменения.

Проверка восстановления проекта с записями

Проверяет текущую схему, записи, ссылки и SQLite. Здесь показывается только техническая сводка — экспорт записей доступен исключительно через доверенную локальную библиотеку, а восстановление выполняется в новый проект.

Права пользователей, workflows и подключения не копируются. Архив содержит данные клиентов и требует защищённого офлайн-хранения.

# OSGARD SUPREME DIRECTOR M200 — прогноз денежных разрывов

Новый исполняемый локальный модуль `Director200(Director199)`. Все расчёты **гипотетические**, это не банковская выписка и не подтверждение оплаты.

## Возможности

- Дополнительная таблица SQLite `delivery_expense_schedule`, связывающая плановые расходы с датами. Существующие расходы и проекты M192–M199 остаются без изменений.
- `commerce.cashflow.schedule.set` — назначение/перенос срока конкретного планового расхода с `expected_expense_version`, `expected_schedule_version`, транзакционной идемпотентностью и проверкой ролей.
- `commerce.cashflow.schedule.list` — перечень запланированных расходов конкретного проекта.
- `commerce.cashflow.forecast` — помесячный прогноз баланса, денежного разрыва и источников неопределённости.
- `commerce.cashflow.compare` — сопоставление 2–3 сценариев по доле ожидаемых поступлений, перерасходу и условному начальному балансу.
- Интерфейс **/cashflow/**, только localhost. Панели предыдущих этапов доступны по /portfolio/, /finance/, /projects/, /studio/.

Формулы: ожидаемые поступления = будущие плановые поступления × `collection_rate_bp/10000`; ожидаемые расходы = датированные плановые расходы × `(10000+cost_overrun_bp)/10000`. Баланс месяца = начальный условный баланс + поступления − расходы. Фактические прошлые расходы не вычитаются повторно. Денежные суммы в целых копейках, округление до копейки арифметически, без float.

Непросроченные суммы за пределами горизонта, **просроченные** и **без даты** возвращаются отдельно. Если даты расходов не введены, модель явно сообщает `INCOMPLETE_DATES`. Невозможно считать это достоверным прогнозом банковского счёта.

## Запуск

Из корня репозитория:

```bash
export PYTHONPATH="$(pwd)/supreme-director/m192:$(pwd)/supreme-director/m193:$(pwd)/supreme-director/m194:$(pwd)/supreme-director/m195:$(pwd)/supreme-director/m196:$(pwd)/supreme-director/m197:$(pwd)/supreme-director/m198:$(pwd)/supreme-director/m199:$(pwd)/supreme-director/m200"
python3 -m osgard_m200 init --db ./director200.sqlite --tenant "Моя организация"
python3 -m osgard_m200 serve --db ./director200.sqlite --port 8720
```

Откройте http://127.0.0.1:8720/cashflow/. Токен владельца показывается один раз; не публикуйте его в чатах, issue или Git. Для существующей M199-базы: остановите процесс M199, создайте проверенную резервную копию SQLite (с учётом WAL), используйте `serve --db ./existing.sqlite` — это **аддитивная** миграция.

## Тестирование

```bash
python3 -m unittest discover -s supreme-director/m200/tests -p 'test_*.py' -v
node --check supreme-director/m200/osgard_m200/web/app.js
```

Из оригинальных 180 пакетов **0 независимо принято**. Production **NO-GO**; основная ветка не изменяется. Браузерная визуальная приёмка требуется отдельно. Сводный прогноз ограничен 1000 видимыми проектами (наследование лимита M199); сценарии — 1–18 месяцев. Контрольный баланс вводится вручную и не связан с банковским API.

# OSGARD SUPREME DIRECTOR M199 — Сводная финансовая аналитика

**Статус:** разработано для локального использования. `main`/production не меняются. Внешние банковские операции отсутствуют.

## Что реализовано

Новый исполняемый модуль `osgard_m199` наследует M198, но **не создаёт новых таблиц и не дублирует финансы**. Операции только на чтение:

| API operation | Что возвращает |
|---|---|
| `commerce.portfolio.overview` | Сводные бюджеты, факт, план, прогноз, ожидаемые/ручные поступления, риски, проекты |
| `commerce.portfolio.calendar` | Календарь ожидаемых поступлений 1–18 месяцев, отдельная ручная регистрация, затраты |
| `commerce.portfolio.export` | Защищённый от CSV-formula-injection экспорт доступных проектов |

Данные привязаны к `tenant_id`. Роль `owner` видит все проекты своей организации; `operator` — только созданные им; `viewer` не видит финансов. Показатели рассчитываются по действительным строкам SQLite. Все суммы — **целые копейки**, не float. Никаких демонстрационных сумм в рабочем интерфейсе.

Указанный оператором статус `recorded` **не доказывает банковский платёж**. В M198 у плановых расходов отсутствуют даты платежа, поэтому M199 сознательно не выдаёт их за точный кассовый прогноз. Календарь отображает *запланированные даты получения денег*, а не полную модель банковского cash flow. Просроченные, без даты и выходящие за горизонт обязательства указаны отдельно; сверка гарантирует, что суммы не теряются.

## Локальный запуск

Распакуйте полный комплект M192–M199. На Windows запустите `START_OSGARD_M199_WINDOWS.cmd`, на Linux/macOS — `bash START_OSGARD_M199_LINUX_MAC.sh`. По умолчанию панель: **http://127.0.0.1:8719/portfolio/**.

Вручную из корня комплекта:

```bash
export PYTHONPATH="$(pwd)/supreme-director/m192:$(pwd)/supreme-director/m193:$(pwd)/supreme-director/m194:$(pwd)/supreme-director/m195:$(pwd)/supreme-director/m196:$(pwd)/supreme-director/m197:$(pwd)/supreme-director/m198:$(pwd)/supreme-director/m199"
python3 -m osgard_m199 init --db ./osgard-local.sqlite --tenant 'Моя организация'
python3 -m osgard_m199 serve --db ./osgard-local.sqlite --port 8719
```

Создание откажется перезаписывать существующую БД. Чтобы открыть накопленные данные M198, не вызывайте `init`, а запустите `serve --db <существующая-БД>` после проверенной резервной копии. Токен выводится один раз при создании и **никогда не сохраняется в интерфейсе**; после перехода на другую страницу потребуется войти заново.

## Тесты

```bash
python3 supreme-director/m199/verify_source.py
node --check supreme-director/m199/osgard_m199/web/app.js
python3 -m unittest discover -s supreme-director/m199/tests -p 'test_*.py' -v
python3 supreme-director/m199/smoke.py
```

Для зависимостей требуется `PYTHONPATH`, указанный выше. В CI дополнительно выполняются регрессии M192–M198 на Python 3.11 и 3.13. Необязательный браузерный smoke в среде с доступным Chromium должен запускаться отдельно; прохождение Python HTTP тестов не равняется визуальной проверке.

## Границы и ограничения

- Только localhost / loopback. Backend не принимает публичную привязку.
- Ответы API не разрешают публикацию, проводку платежей или изменение права доступа.
- Сводка ограничена **1000 видимыми проектами**; при превышении честно отклоняет отчёт, а не показывает частичные финансовые итоги.
- Часть проектов без бюджета учитывается отдельно; сумма бюджетов включает только заданные бюджеты, не подменяет `NULL` нулём.
- Экспорт CSV нейтрализует формулы в данных клиентов и проектов.
- Для календаря доступно от 1 до 18 месяцев, UTC, даты от 2000 до 2099 года.
- Изначальные 180 инженерных задач не прошли независимую приёмку: `0/180`; production `NO_GO`.

# OSGARD SUPREME DIRECTOR — M195: сотрудники, назначение и сроки

Дата: 5 ноября 2026. Ветка: `recovery/supreme-director-m187-20261104`, PR #7.

## Реализовано

Создан новый исполняемый пакет `osgard_m195` поверх модулей M192–M194 без замены их кода. Добавлены транзакционные таблицы `team_work`, `work_history`, `team_notices` в локальной SQLite. Добавлено 12 операций с проверкой организации и роли:

- список активных сотрудников, создание задач, список, карточка;
- назначение владельцем, переходы статусов, заметки, история изменений;
- локальные уведомления при назначении и смене статуса;
- явная проверка дедлайнов, личный inbox и отметка прочтения;
- подсчёт открытых, закрытых, просроченных задач и задач ближайших суток.

Новая вкладка **Команда** интегрирована в русскоязычную студию M194; все данные приходят из локального API. Создание и изменение задач работают через настоящую базу, не демонстрационные массивы. Внешние уведомления и автоматические фоновые задачи намеренно не внедрялись.

## Проверки

- M195: 46/46 локальных автоматизированных тестов PASS (tenant isolation, RBAC, versioning, idempotency, concurrent writes, history, notifications, HTTP/CSP).
- M192: 46/46 регрессионных PASS.
- M193: 40/40 регрессионных PASS.
- M194: 35/35 регрессионных PASS.
- **Всего 167/167 Python-тестов локально PASS.**
- `node --check` интерфейса — PASS; `python -m py_compile` — PASS.
- Реальная проверка страницы в Chromium **не выполнена**: среда блокирует `http://127.0.0.1` (`net::ERR_BLOCKED_BY_ADMINISTRATOR`); проверка HTTP GET/POST проходит отдельно.

## Инженерные ограничения

- Отсутствует синхронизация с внешними мессенджерами, push и email. Уведомления — только внутренняя очередь SQLite.
- SLA вычисляется при чтении; проверки сроков запускаются кнопкой. Никакого скрытого фонового мониторинга.
- Локальная SHA-цепочка и SQL-триггеры **не равны** независимо подписанному журналу. Для защищённого хранения нужны внешние якоря M190/M191.
- Интерфейс требует реальной визуальной QA на мобильном устройстве и в независимом Chromium.
- Работа по 180 оригинальным инженерным пакетам: 0 независимо принятых. Эта новая реализация полезна, но не доказывает готовность всех отдельных первичных продуктов.
- **Production NO-GO**, ветка `main` не меняется.

## Воспроизведение

```bash
export PYTHONPATH="$PWD/supreme-director/m192:$PWD/supreme-director/m193:$PWD/supreme-director/m194:$PWD/supreme-director/m195"
python3 supreme-director/m195/verify_source.py
python3 -m unittest discover -s supreme-director/m195/tests -p 'test_*.py' -v
python3 -m osgard_m195 init --db /tmp/osgard_m195.sqlite --tenant Demo --actor owner
python3 -m osgard_m195 serve --db /tmp/osgard_m195.sqlite --port 8715
```

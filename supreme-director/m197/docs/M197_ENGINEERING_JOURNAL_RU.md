# M197 · Инженерный журнал

Дата: 5 ноября 2026. Ветка: `recovery/supreme-director-m187-20261104`, PR #7.

## Реализованный код

Новая версия `Director197(Director196)` использует общую tenant-изолированную SQLite и старые транзакционные/idempotency операции. Добавлены таблицы `delivery_documents`, `delivery_document_versions`, `delivery_obligations`; два иммутабельных триггера версий, два триггера запрещающие завершение при открытых обязательствах.

Операции API: `commerce.projects.card`, `commerce.projects.health`, `commerce.projects.documents.{list,add,revise,content}`, `commerce.projects.obligations.{list,add,resolve}`. Все записи проходят аутентификацию и optimistic locking. Документы не возвращаются в обычных списках; только по отдельной авторизованной операции.

## Реализованные гарантии

1. `tenant_id` и `actor/role` берутся только из действительного bearer-токена, никогда из пользовательского JSON.
2. Редактирование документов/обязательств доступно владельцу или автору проекта; только владелец снимает обязательства с записанной причиной. Пользователи с ролью viewer видят агрегаты, без содержимого документов и частных деталей.
3. Дублирование запросов безопасно при идентичном idempotency key; конкурентные версии не перезаписывают друг друга.
4. Содержимое документа проверяется перед записью (base64, размер, UTF-8 для текста, PDF magic). Версии файла иммутабельны; SHA-256 проверяется при чтении.
5. Закрытие этапа или всего проекта с открытыми обязательствами невозможно в M197 и блокируется SQL-триггером при старых вызовах M196.
6. Для закрытия обязательства требуется SHA-256 **существующей сохранённой версии документа того же проекта и арендатора**. Произвольные или чужие хеши отклоняются.
7. Все операции формируют новые записи в локальной цепочке событий проекта M196; внешний независимый якорь по умолчанию отсутствует.

## Проверки и ограничения

- Новые unit/integration тесты охватывают миграцию старой M196, авторизацию, межарендаторные запросы, версионирование, одновременные изменения, запрет обходов через старый клиент, повреждение байтов и защиту HTTP.
- Предыдущие тесты M192–M196 запускаются как отдельные регрессионные наборы, исходный код старых версий не изменяется.
- Реальная визуальная проверка в Chromium **не завершена**: локальная навигация заблокирована `ERR_BLOCKED_BY_ADMINISTRATOR`. HTTP и JS проверены отдельно.
- Ограничения: нет большого файлового хранилища, цифровой подписи клиента, внешних систем, production-деплоя и независимой приёмки исходных 180 заданий.

## Откат

Сделать проверенный backup до миграции. Для отмены остановить M197, восстановить предыдущий слепок базы с WAL и снова запустить M196; нельзя просто удалять таблицы вручную или считать старый код aware о новой логике обязательств.

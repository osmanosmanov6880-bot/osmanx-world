# M203 — инженерный журнал 4 больших блоков

Дата: 2026-11-05. Репозиторий osmanosmanov6880-bot/osmanx-world, ветка recovery/supreme-director-m187-20261104, draft PR #7.

## A. Планы

Модуль plans.py: устойчивое хранилище финансовых планов на базе предупреждений M201 и исходных наблюдений M202. Описаны цель, гипотеза, направление метрики, срок и статусы. Конкурентная защита: версия, идемпотентный ключ, unique constraint открытых планов. История изменений append-only SHA-256.

## B. Выполнение

Этапы связывают действия с настоящими задачами M195. При создании обновляются team_work, work_history и team_notices в одной SQLite-транзакции. Доступ владельца и назначенного оператора разделён. Закрытие плана не отменяет неоконченные задачи незаметно.

## C. Проверка

Модуль outcomes.py сравнивает исходный и новый снимки одного риска, проверяет политику и хеш-цепочку, рассчитывает улучшение и требует завершения M195. Запись оценки неизменяема, принятие или отказ фиксируются отдельной рецензией owner. Нет заявлений о доказанной прибыльности, фактической оплате, причинности или независимом аудите.

## D. Продуктовый интерфейс + QA

Русский адаптивный /actions/, полноценные HTTP API, owner-only аналитика, операторские задания без сумм, JSON report и CSV (formula injection guard). CI проверяет новый набор unit/adversarial/HTTP тестов, synthetic end-to-end и всю регрессию M192–M202 на Python 3.11/3.13. Счётчик независимой приёмки исходных требований остаётся 0/180.

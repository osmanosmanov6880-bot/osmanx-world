# OSGARD SUPREME DIRECTOR · M198 — Финансы проектов

**Работающий локальный модуль**, продолжает M192–M197 без удаления прежних таблиц. Суммы — только целые копейки. Все операции только с SQLite; **нет подключений к банкам, отправок сообщений, платежей, фоновых задач или деплоя**.

## Возможности

- Бюджет в рублях с проверкой версии и журналом изменения.
- Плановые расходы, перевод в фактические, отмена с сохранением причины и истории.
- Ожидаемые оплаты и сроки, ручная запись получения только с подтверждающим документом текущей версии **того же проекта**.
- Прогноз затрат = факт + оставшиеся плановые затраты; отклонение = прогноз − бюджет.
- Оценка ожидаемой маржи = ожидаемые оплаты минус прогноз затрат; это **упрощённая оценка**, не бухгалтерская прибыль.
- Финансовая карточка проекта, список записей, просроченные оплаты, журнал SHA-256.
- Русская адаптивная панель `/finance/`, локальный API `/v1/execute`.
- SQLite миграции только добавляют три таблицы, не изменяя структуру M192–M197.

## Запуск на Windows

Распакуйте комплект M192–M198. Откройте `START_OSGARD_M198_WINDOWS.cmd` в корне комплекта. Если базы нет, скрипт создаст её и покажет одноразовый токен. Затем зайдите на `http://127.0.0.1:8718/finance/`. Для существующей базы сначала сделайте резервную копию, затем запускайте сервер с `--db`.

## Запуск в Linux/macOS

Из корня комплектa выполните `bash START_OSGARD_M198_LINUX_MAC.sh`. Потребуется Python 3.11+; внешние Python-библиотеки для M198 не требуются.

## Ручные команды

Сделайте все пакеты доступными Python через `PYTHONPATH`:

```bash
export PYTHONPATH="$(pwd)/supreme-director/m192:$(pwd)/supreme-director/m193:$(pwd)/supreme-director/m194:$(pwd)/supreme-director/m195:$(pwd)/supreme-director/m196:$(pwd)/supreme-director/m197:$(pwd)/supreme-director/m198"
python3 -m osgard_m198 init --db ./local_m198.sqlite --tenant 'Моя организация'
python3 -m osgard_m198 serve --db ./local_m198.sqlite --port 8718
```

`init` **никогда не перезапишет** существующую базу. При наличии данных после M197 используйте `serve`: он применяет только добавочные таблицы M198.

## Тесты

```bash
python3 -m unittest discover -s supreme-director/m198/tests -p 'test_*.py' -v
python3 supreme-director/m198/smoke.py
node --check supreme-director/m198/osgard_m198/web/app.js
python3 supreme-director/m198/verify_source.py
```

Тесты проверяют изоляцию организаций, 3 роли, целые копейки, оптимистичную блокировку, документы, идемпотентность и HTTP-доступ.

## Безопасность и точные границы

- `recorded` обозначает запись оператора с документом, **не** банковский платёж. Документ может быть локальным, его происхождение не является независимым.
- Исторические 180 задач не подтверждены независимой приёмкой: **0/180**. Production — **NO-GO**.
- На публичный IP не привязывается; HTTP работает только через loopback.
- Финансовые данные читает и изменяет только владелец организации или создатель проекта. Viewer и посторонний сотрудник не допускаются.
- Защита хеш-цепочки выявляет локальные изменения, но без внешнего контрольного якоря не доказывает защиту от привилегированной полной переписи.
- Нельзя использовать суммы в качестве налогового учёта или реальной банковской выписки.

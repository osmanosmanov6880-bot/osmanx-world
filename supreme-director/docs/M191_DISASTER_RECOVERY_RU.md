# OSGARD SUPREME DIRECTOR — партия M191: crash-consistent backup & restore

Дата: 2026-11-04. Ветка: `recovery/supreme-director-m187-20261104`. PR #7.

## Основание

M189 проверяет доказательства; M190 записывает результаты в локальный SQLite-журнал с хеш-цепочкой. M191 решает следующую проблему: как получить достоверную резервную копию активной WAL-базы и восстановить её из изолированного архива, не удалив существующее состояние.

## Реализованные компоненты

- `m191/recovery.py`: SQLite online backup -> staging -> валидация -> атомарное опубликование каталога (только при отсутствии назначения); проверка полноценного SQLite и оригинального M190 event-head; восстановление в **новый** SQLite-файл.
- `m191/cli.py`, `m191/__main__.py`: команды `backup`, `verify`, `restore`, коды отказа и JSON-отчёты.
- `m191/tests/test_recovery.py`: 26 локальных adversarial-тестов; включая порчу, чужой якорь, stale head, symlink, перезапись, оборванную операцию и восстановление.
- `m191/smoke.py`: реальный локальный (синтетический) путь M189 → M190 → M191 → восстановление → 180 BLOCKED_UPSTREAM.
- `m191/verify_source.py`, `M191_SOURCE_MANIFEST.json`: SHA-256 файлов исходников M191 и точный инвентарь.

## Контракт

1. Оператор заранее сохраняет head-anchor M190 в независимом надёжном хранилище и связывает его с конкретной доверенной ревизией.
2. `backup` требует валидный anchor, копирует работающую SQLite транзакционно через backup API, повторно сверяет head, проверяет снимок; только затем делает видимым полный каталог.
3. `verify` запрещает лишние файлы, небезопасные ссылки, изменённые байты SQLite/якоря, непрошедшую `PRAGMA integrity_check` и расхождение M190.
4. `restore` восстанавливает только под **новым** именем. Сначала копия и проверка, затем публикация без перезаписи.
5. Модуль никогда не меняет статус исторической приёмки (0/180) и не разрешает production.

## Ограничения

Этот механизм локальный; нет распределённого консенсуса, S3 Object Lock, immutable storage, удалённого резервирования, signed time-stamping и аппаратного root of trust. SHA без доверенно закреплённого anchor не подтверждает авторство и не доказывает неизменность истории. Основные 180 задач остаются `BLOCKED_UPSTREAM`; настоящее межсистемное E2E ещё не выполнено.
